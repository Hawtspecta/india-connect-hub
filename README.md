# India Connect Hub: A Cultural Experience Organization

A modern, high-impact website designed for a multidisciplinary creative organization specializing in performing arts, cultural experiences, event production, workshops, and digital content.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/en/) (v18.0.0 or higher)
- npm or bun

### Installation
```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd india-connect-hub

# Install dependencies
npm install
```

### Development
```bash
# Start the dev server
npm run dev
```
The application will be available at `http://localhost:8080`.

## 🎨 Design System Strategy: "The Digital Curator"

The design balances cultural authenticity with modern global standards. It feels premium, clean, and high-end.

### Color Palette
| Color | Purpose | Hex/HSL |
| :--- | :--- | :--- |
| **Deep Madder Red** | Primary Action, Accents, Branding | `hsl(354, 70%, 45%)` |
| **Warm Ivory / Cream** | Primary Background, High-end feel | `hsl(45, 20%, 96%)` |
| **Shimmer Gold** | Secondary accents, Luxury highlights | `hsl(43, 80%, 48%)` |
| **Warm Black** | Typography, Deep contrast | `hsl(30, 20%, 8%)` |
| **Soft Slate** | Muted text, Borders, Secondary info | `hsl(215, 15%, 45%)` |

### Typography
- **Display (Serif)**: *Playfair Display* — headlining, storytelling, and heritage moments.
- **Body (Sans-Serif)**: *DM Sans* — clean, global, and highly readable.

## 🗺️ Website Structure & Sitemap

The platform is designed to scale from a single-page storytelling experience to a full-scale global creative hub.

### 1. Homepage Sections
- **Hero Section**: High-resolution video and storytelling tagline.
- **About Section**: Mission, vision, and scale metrics (stats).
- **Services Section**: Interactive showcase of core offerings.
- **Featured Work**: Marquee-style project portfolio.
- **Partners & Clients**: Corporate and cultural collaborators.
- **Testimonials**: Global voices and social proof.
- **Contact**: Advanced inquiry form with custom selection UI.

### 2. Proposed Navigation Map
- `/home`: Current primary experience.
- `/work`: Case studies and individual project deep-dives.
- `/services`: Details for Performing Arts, Festivals, and Production.
- `/digital`: Archive of Podcasts, Performances, and Documentaries.
- `/about`: Detailed origin story and core team.
- `/contact`: Global reaching and collaboration inquiries.
